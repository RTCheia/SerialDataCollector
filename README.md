# SerialDataCollector

多通道高频串口数据采集与实时可视化系统 (Multi-channel High-frequency Serial Data Collector & Visualizer)

[English Documentation](README_EN.md) | [中文说明](README.md) | [ Releases 编译版本下载 ](https://github.com/RTCheia/SerialDataCollector/releases)

## 🌟 项目简介

**SerialDataCollector** 是一款面向工业与科研测试场景的高性能多通道串口数据采集、实时波形绘制与数据落盘软件。  
采用 Python + PySide6 + PyQtGraph 构建，具备硬件解耦的多线程流水线设计，在高采样率（100Hz ~ 1000Hz+）与长时间连续采集场景下保持极致的流畅性与数据零丢失。V7.1 在 V7.0 离线数据看板基础上，新增「数据分析与处理」一键精度核验。

---

## ✨ 核心特性

- **多通道高频并发采集**：支持多路串口（默认3通道）独立配置波特率、端口与校验位，硬件断流自动告警重连。
- **高帧率平滑波形渲染**：基于 PyQtGraph 与双缓冲环形队列，支持万级点阵高刷新率实时绘制，UI 无假死卡顿。
- **灵活的 X 轴视窗**：
  - **动态点数范围**：支持在 `10` ~ `2000` 点之间自由调整显示窗口宽度（默认 100 点）。
  - **坐标单位切换**：支持「**帧号 (Frame)**」与「**时间秒 (s)**」随时切换；时间模式下可自定义标定采样率（默认 200 Hz）。
- **专业级多格式数据落盘**：
  - 支持 CSV、TXT 与二进制原始日志输出。
  - 支持通道分流记录与合并时间戳对齐存储。
- **高可靠收尾与防丢保护**：
  - 采集工作线程与 UI 完全解耦，遇到窗口异常关闭或系统关机时触发安全收尾拦截，确保缓冲区所有数据完全落盘。
- **内置全自动自检诊断**：
  - 无需物理串口设备，内置 3 路仿真数据源。
  - 支持 `--self-test`（记录完整性、丢包模拟、收尾校验）与 `--ui-smoke-test`（界面启动渲染回归测试）。
- **离线数据分析看板（V7.0 起）**：
  - 入口始终可用，打开前手动选择已记录会话；与完整波形 PNG 并列且互不依赖。
  - 支持缩放、拖动和帧型感知显示；四组图表滚轮缩放互不联动。
  - 四阶低通、一阶高通、带通和移动平均可按图独立设置与取消，并支持处理后 CSV 导出及当前图表 PNG 保存。
  - 详细设计见 `V7_0_数据看板设计.md`。
- **数据分析与处理（V7.1）**：
  - 选一个已结束会话、导入同一次试验的光捕 CSV，一键给出 UWB 精度结论。
  - 输出运动过程 RMS、最大误差、两状态行程误差与相对误差，并按 30 mm 判据给出合格／部分合格／不合格。
  - 曲线与处理后数据可直接导出，结果同时落盘到 `<会话>/analysis/`。
  - 详细设计见 `V7_1_数据分析与处理设计.md`。

## 📊 数据分析与处理（V7.1）

主界面「进入数据看板」右侧的「数据分析与处理」，面向**单次运动**的 UWB 精度核验，用在每次试验收工后。

### 使用步骤

1. 点「选择会话…」，选一个已结束的采集会话（包含 `chN/data.txt`）。通道按 `summary.json` 的 `frame_header` 识别，`EB 92` 为 UWB、`EB 91` 为 IMU，不依赖 ch1/ch2 的顺序。
2. 点「导入光捕…」，选 OptiTrack 导出的 CSV（`*-Tracker0.csv` 与旧版 `*-object.csv` 均可，自动跳过 `[SegmentData]` 之前的表头）。两个路径都会被记住，下次打开直接定位到上次的目录。
3. 点「开始处理」，几秒内给出结论。

### 输出

| 位置 | 内容 |
|---|---|
| 结论条 | 合格／部分合格／不合格，附行程测量值与真值 |
| 指标卡 | 运动过程 RMS、最大误差、两状态行程误差、相对误差 |
| 上图 | 光捕真值与 UWB 测量位移，四条竖虚线标出两个 5 帧取值区间 |
| 下图 | 运动过程内的逐点误差，绿色带为 ±30 mm |
| 导出 | 图表 PNG、处理后 CSV（时间／光捕／UWB／误差） |
| 落盘 | `<会话>/analysis/分析结果.txt` |

### 处理口径

与 `D://1120//交付版标准流程.md` 完全一致，实现见 `analysis.py`：

1. 两路各自找唯一行程，上升沿 15%→85% 中点作锚点，`b = T0_UWB − T0_光捕` 单次平移对齐；
2. 截取 `[T0 − 900, T0 + 1100]` 共 2000 ms；
3. UWB 位移 5 点中值滤波（边界延拓）；
4. 两段 500 ms 长窗求比例 k，按 `1 + 0.9(k − 1)` 保守采用；
5. 端点各 5 帧按 0.9→0.5 / 0.5→0.9 权重过渡，运动过程等权 0.5；
6. 评估：运动过程（两状态之间）逐点 RMS 与最大误差；两状态各 5 帧求行程误差；判据 30 mm。

### 前提与限制

- 数据必须是**单次完整运动**（一次分离、一次截停）。多次往返的记录会配对到不同行程，结论无意义。
- 运动总时长需落在 2 秒窗口内；超长行程会报「窗口内位移没有达到 95%」。
- 只评估沿运动主方向的位移精度，横向未纳入。

## 🚀 快速上手

### 1. 直接运行 Release 独立可执行程序
若不需要修改源码，可前往 **[GitHub Releases](https://github.com/RTCheia/SerialDataCollector/releases)** 下载最新编译好的独立程序：
- 文件名：`SerialDataCollector_V7_1.exe`
- 无需安装 Python 环境，双击即可运行。

### 2. 源码环境运行
确保已安装 Python 3.13：

```bash
# 1. 克隆代码仓库
git clone https://github.com/RTCheia/SerialDataCollector.git
cd SerialDataCollector

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行主程序
python main.py
```

### 3. 自检与自动化测试
在无物理串口硬件时，可直接通过内置自检验证软件完整性：

```bash
# 自动化功能与异常恢复测试
python main.py --self-test _temp/data/selftest_run

# 界面冒烟与绘图渲染测试
python main.py --ui-smoke-test
```

## 📦 打包（PyInstaller 单文件）

版本命名沿用 `SerialDataCollector_V<主>_<次>.exe`，spec 与构建脚本放在 `_temp/tools/`，产物落在工程根目录，日志写入 `log/`。

```powershell
# V7.1（当前版本）
pwsh -NoProfile -ExecutionPolicy Bypass -File "_temp/tools/build_v7_1.ps1"
```

要点：

- 打包解释器固定用 `C:\ProgramData\miniconda3\python.exe`，脚本里已把 `C:\ProgramData\miniconda3\Library\bin` 加入 `PATH`，否则单文件缺少 `ffi.dll`，启动会报 `DLL load failed while importing _ctypes`；
- spec 显式剔除 `PyQt5/PyQt6/PySide2/tkinter/scipy/pandas/...`，并在收集后去掉 `icuuc.dll`、`icudt78.dll`，避免与 Qt 6.11 使用的系统 ICU 冲突；
- 新增模块只要是被 `main.py` 间接 import 的纯 Python 文件，会自动打进包里，无需改 spec。
