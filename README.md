# SerialDataCollector

多通道高频串口数据采集与实时可视化系统 (Multi-channel High-frequency Serial Data Collector & Visualizer)

[English Documentation](README_EN.md) | [中文说明](README.md) | [ Releases 编译版本下载 ](https://github.com/RTCheia/SerialDataCollector/releases)

## 🌟 项目简介

**SerialDataCollector** 是一款面向工业与科研测试场景的高性能多通道串口数据采集、实时波形绘制与数据落盘软件。  
采用 Python + PyQt5 + PyQtGraph 构建，具备硬件解耦的多线程流水线设计，在高采样率（100Hz ~ 1000Hz+）与长时间连续采集场景下保持极致的流畅性与数据零丢失。

---

## ✨ 核心特性

- **多通道高频并发采集**：支持多路串口（默认3通道）独立配置波特率、端口与校验位，硬件断流自动告警重连。
- **高帧率平滑波形渲染**：基于 PyQtGraph 与双缓冲环形队列，支持万级点阵高刷新率实时绘制，UI 无假死卡顿。
- **灵活的 X 轴视窗**：
  - **动态点数范围**：支持在 `10` ~ `2000` 点之间自由调整显示窗口宽度（默认 100 点）。
  - **坐标单位切换**：支持「**帧号 (Frame)**」与「**时间秒 (s)**」随时切换；时间模式下可自定义标定采样率（默认 200 Hz）。
- **专业级多格式数据落盘**：
  - 支持 CSV、TXT 与二进制原始日志输出。
  - 支持通道分流记录与合并时间戳对齐存储。
- **高可靠收尾与防丢保护**：
  - 采集工作线程与 UI 完全解耦，遇到窗口异常关闭或系统关机时触发安全收尾拦截，确保缓冲区所有数据完全落盘。
- **内置全自动自检诊断**：
  - 无需物理串口设备，内置 3 路仿真数据源。
  - 支持 `--self-test`（记录完整性、丢包模拟、收尾校验）与 `--ui-smoke-test`（界面启动渲染回归测试）。

## 🚀 快速上手

### 1. 直接运行 Release 独立可执行程序
若不需要修改源码，可前往 **[GitHub Releases](https://github.com/RTCheia/SerialDataCollector/releases)** 下载最新编译好的独立程序：
- 文件名：`SerialDataCollector_V5_2.exe`
- 无需安装 Python 环境，双击即可运行。

### 2. 源码环境运行
确保已安装 Python 3.9 ~ 3.12：

```bash
# 1. 克隆代码仓库
git clone https://github.com/RTCheia/SerialDataCollector.git
cd SerialDataCollector

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行主程序
python main.py
```

### 3. 自检与自动化测试
在无物理串口硬件时，可直接通过内置自检验证软件完整性：

```bash
# 自动化功能与异常恢复测试
python main.py --self-test _temp/data/selftest_run

# 界面冒烟与绘图渲染测试
python main.py --ui-smoke-test
```

## ⚙️ 配置说明

| 配置项 | 范围 / 选项 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| **视窗范围** | 10 ~ 2000 点 | 100 点 | 波形横坐标展示的最新数据点数量 |
| **X轴显示模式** | 帧号 (Frame) / 时间 (s) | 帧号 | 切换波形图横轴为帧序号或时间秒 |
| **标定采样率** | 1 ~ 2000 Hz | 200 Hz | 在时间显示模式下用于将帧数换算为秒数 |
| **串口波特率** | 9600 ~ 921600 | 115200 | 各通道独立配置 |
